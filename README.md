# Система обробки фінансових транзакцій

Міні-додаток для моніторингу та обробки фінансових транзакцій, розроблений з використанням архітектурного шаблону **MVC** та паттернів проєктування **Observer**, **Decorator** та **Strategy**.

## 1. Запуск проєкту

Щоб запустити програму, виконайте команду в терміналі:

```bash
npx tsx src/index.ts
```

## 2. Результати роботи (Консольний лог)

Демонстрація зміни стратегії на льоту, застосування декораторів та спрацювання спостерігачів:

```text
=== СТАРТ ПРОГРАМИ ===

--- Сценарій 1: Стандартний податок (18%) + Логування ---
[Логер] Отримано дані: [LOG 2026-10-01T09:39:55.578Z] Обробка суми: 1180
[Email] Відправлено лист з даними: [LOG 2026-10-01T09:39:55.578Z] Обробка суми: 1180

=== ВИВІД VIEW ===
Оновлені дані транзакції для відображення:
[LOG 2026-10-01T09:39:55.578Z] Обробка суми: 1180
==================

--- Сценарій 2: Зміна стратегії на льоту + Шифрування + Логування ---
-> КОНТРОЛЕР: Зміна стратегії на IT Sector (5%)...
[Логер] Отримано дані: [LOG 2026-10-01T09:39:55.579Z] [Зашифровано: 0012 :имус акборбО]
[Email] Відправлено лист з даними: [LOG 2026-10-01T09:39:55.579Z] [Зашифровано: 0012 :имус акборбО]

=== ВИВІД VIEW ===
Оновлені дані транзакції для відображення:
[LOG 2026-10-01T09:39:55.579Z] [Зашифровано: 0012 :имус акборбО]
==================
```
